Value Type 				Reference Type

Value Types
		Value types directly contain their data
		Stored on stack memory location
		-------------------------------------------------------
		Example 
		Primitive data types (int , char, float,double , long ,decimal,bool), Struct , Enum, Nullable , Tuple
	
		similar Call by Value
		If we pass any value type as a parameter to any method, 
		Changes done inside method , does not reflect back calling method(Main method)
		

	Reference Types
		Reference types store a reference to their data.
		Stored on Heap memory location
		-------------------------------------------------------
		Example
		Class . Object , Array , string, interface, dynamic,delegate 
		
		similar Call by Reference
		If we pass any reference type as a parameter to any methods, 
		Changes done inside method , reflect back calling method(Main method)

		Default value NULL
	
	Type Conversion
	
		Store one data type value into other data type 

		Implicit
			We store smaller data type value into larger data type
			Compiler automatically converts without explicitly mention conversion type.

		int count=100;
		double doubleCount=(double)count;
	
		double doubleCount=count;   //OK 

		Explicit
			We store larger data type value into smaller data type
			Compiler does not automatically converts , we need explicitly mention conversion type.

		       double doubleNumber=1000.00;
			int number=(int)doubleNumber;
